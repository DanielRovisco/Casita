# Casita

Aplicação estática (HTML/CSS/JS puro) para acompanhar a poupança para casa. Sem build, sem dependências — basta abrir `index.html` ou servir os ficheiros estaticamente.

- `index.html` — estrutura da página
- `style.css` — estilos, incluindo as media queries mobile
- `script.js` — lógica (tabela de depósitos, totais, persistência em `localStorage`)

## Workflow

- Ao terminar uma tarefa (alterações de código concluídas e válidas), faz sempre commit e push das alterações para o branch atual. Não esperes que seja pedido explicitamente.
